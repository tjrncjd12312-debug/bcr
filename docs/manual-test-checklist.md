## 수동 체크리스트 (엔드투엔드)

### 사전 준비
- 앱 실행 후 네트워크 연결 확인 (Wi-Fi/LAN 정상 여부).
- 캐시/쿠키 초기화가 필요하면 앱 재시작.

### 1. 로그인/세션
- 올바른 계정으로 로그인 시 성공 토스트 확인.
- 잘못된 비밀번호 입력 시 오류 토스트 확인.
- 세션 만료/오프라인 시 헤더 배너(재연결) 및 CTA 비활성화 확인.

### 2. 카지노 연결
- `카지노 연결`/`재연결` 버튼 클릭 시 브라우저가 정상 실행되는지 확인.
- 연결 후 헤더 상태가 `connected`로 변경되고 토글(반자동/가상배팅)이 활성화되는지 확인.

### 3. 로비/방 리스트
- 로비 필터/정렬 동작 확인(게임 수/이름/마틴).
- 방 선택 시 가운데 패널에 방 이름/예측 카드가 갱신되는지 확인.
- 리스트 타이머 배지(남은 초) 표시/카운트다운 확인.

### 4. 예측/결과 흐름
- 예측 발생 시 카드 강조, 리스트 플래시, 로그 기록을 확인.
- 결과 도착 시 승/패 오버레이와 로그가 일치하는지 확인.
- 스킵 예측 시 O/X 뱃지가 즉시 사라지는지 확인.

### 5. 가상배팅
- 가상배팅 ON/OFF 토글 동작 확인.
- 배팅/결과 로그가 금액·마틴 레벨과 함께 기록되는지 확인.
- 잔액/손익/대기 중 금액이 오른쪽 패널에 즉시 반영되는지 확인.

### 6. 반자동 모드
- 반자동 전환 시 창 크기를 줄여도 내용이 스크롤로 모두 노출되는지 확인.
- 방 자동 찾기/수동 입장 버튼이 작동하고 예측/로그가 표시되는지 확인.
- 연결 끊김/오류 시 토스트+로그로 알림이 표시되는지 확인.

### 7. 반응형
- 창 너비를 1100px 이하로 줄였을 때 패널이 단일 컬럼으로 정렬되고 헤더/버튼이 겹치지 않는지 확인.
- 모바일 뷰(480px 이하)에서 헤더/패널이 깨지지 않고 주요 CTA가 노출되는지 확인.

### 8. 종료/로그아웃
- 로그아웃 시 상태가 초기화되고 재로그인 가능 여부 확인.
